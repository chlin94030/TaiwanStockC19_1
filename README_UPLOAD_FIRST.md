# Alpha Radar V19.0｜近年歷史驗證與日線選股
交付日期：2026-10-16　｜　程式入口：`app.py`　｜　Python 3.11 或 3.12 建議

## 這次交付的內容
這是完整可執行的原始碼，不是只有回測規格。V19 以相同因子函式執行日常排名及歷史重播，支援下載近 1～3 年日線、10 個分段隨機基準日、5／20／60 交易日報酬，以及只使用當時已完成資料的權重比較。舊版 V18.21 工作台仍保留，可由側欄開啟。

**目前交付狀態：程式及離線測試完成；本環境未取得完整近年行情，因此沒有附上真實十日期回測收益，也沒有宣稱已找到最佳權重。** 執行後，真正的資料、結果及權重會產生在 `data/v19/`，並顯示在「歷史驗證」。不會把測試資料自動載入正式 App。

## GitHub／Streamlit 部署
1. 將完整 ZIP 解壓，把全部檔案放在現有 repository 根目錄，覆蓋同名檔案。不要只上傳 ZIP，也不要只換 `app.py`。保留原本 `data/`、Secrets 及歷史 SQLite。
2. Streamlit 主程式指定 `app.py`；套件由 `requirements.txt` 安裝。版本應顯示 **V19.0**。
3. 側欄預設近 3 年、100 檔、截止前一日；按 **「下載近年資料＋執行驗證」**。同一任務不會因手機重連重複啟動。已有快取可按「只用快取執行驗證」。
4. 等流程完成後，依序查看「選股與規劃」「歷史驗證」「個股診斷」。不用把舊報價或舊 SQLite 刪掉重來。

沒有要求付費資料授權才能啟動。FinMind Token 可選，若有可在 Streamlit Secrets 設定：
```toml
FINMIND_TOKEN = "your_own_token"
```
不必把 Token 放進 GitHub。沒有 Token、服務限流或來源無法連線時，程式會保留已下載資料、嘗試備援或清楚回報原因；不保證免費來源在任何時間／雲端主機都能取得全部股票。

## 取得資料的方式
- 主要來源：FinMind 日線；備援：Yahoo 日線；有限額的證交所月資料作上市個股額外備援。
- 每股票一次要求近年區間，不做每交易日逐日網路請求。保存逐股快取、來源、日期及內容摘要。
- 未指定股票池時，從資料商最新上市櫃名單用固定種子抽樣。預設 100 檔是**研究樣本池，不是全市場**；名單查詢失敗時使用明示的 54 檔救援池。
- 新版會以唯讀方式嘗試使用原有 `daily_prices.sqlite`，不改寫舊資料表。
- 請注意：最新股票母體不能證明歷史上當時的全體成分；存活者偏差尚未排除。不能把這個研究稱為「全台股、無偏誤」回測。
- 來源資料有還原收盤欄時用於報酬及比例指標；未有還原價時使用原始價格，顯著公司行動斷點停止相關評估。一般除息仍可能影響結果；未還原來源不等同含息總報酬，沒有承諾已完整處理所有公司行動。
- 不同來源不在同一條股票序列裡隨意拼接成假完整歷史。

## 因子與權重
日常選股和回測共用 `v19_features.py`。

### 可直接從日線建立的六組因子
1. 趨勢與均線。
2. 相對 0050 強度。
3. 平台突破位置。
4. KD／MACD／RSI、負乖離修復。
5. W 底、頸線與突破後回測；轉折點須經右側兩根已完成日 K 確認，不能事後偷看低點。
6. 量縮止跌、適度量增、收盤位置等價量訊號。

### 可選的八組證據
營收、獲利品質、外資、投信、外投同步、自營商自行買賣、融資變化、大戶持股變化。勾選「補充營收／法人／融資」時，會嘗試下載來源支援的營收、法人與融資資料；財報及大戶完整歷史可以透過帶公布時間的 CSV 補充。

**不把缺值當成0分或利多。** 權重訓練僅納入訓練集有效覆蓋至少85％的因子群；技術因子可先獨立完成研究。當某次排名缺少太多有權重的因子，該筆不硬算高分。沒有營收成長、正 EPS 與正毛利率證據時，不會標成「業績＋回檔」。

分點、借券、融券、完整週股權資料不是本版新核心的強制輸入；不會假稱這些已全部下載、完成最佳化。舊版相應研究欄仍可使用。

### 調權重不是把分數硬改成正數
每個週期都有明示起始權重。每個基準日先用更早的資料測試最多24組：原權重、單一因子群移除、局部擾動。訓練階段挑出候選，再以較晚的內部驗證區段選擇，之後才評估本次基準日。

效用函數是事先設定的「平均淨報酬 + 0.25 × 平均不利幅度 − 0.15 × 淨報酬標準差」。它是風險偏好，不是已證明的唯一最佳目標。內部改善不足時保留原權重；訓練資料不夠就沿用基準並標示，而不是捏造最佳權重。60日模型在只有1年資料時通常較難取得足夠訓練樣本。

**報表中的 baseline 是 V19 固定起始權重，不是 V18.21 的實際 Alpha 排名，也不是 Gemini。**

## 十日期驗證的交易假設
- 固定種子1900，按可用日期分十段，各抽一個日期；不用事後表現挑「漂亮日期」。
- T日截至當日可得資訊排名；T+1開盤假設進場；T+5／20／60收盤評價。另列相對T日收盤的價格變化。
- 每次各取前5個名額等權重。無成交量、缺進場價、超過預先設定4％開高上限、可辨識的一價異常日，不視為成交；名額留現金，不用後來漲的股票替補。
- 缺未來資料、零成交量出場、可辨識的一價下跌出場、異常未還原斷點，保留失敗狀態，不能默默刪掉可能虧損的股票。
- 股票買賣手續費各0.1425％、股票賣出稅0.3％、每邊滑價0.05％，是可修改的研究假設。0050基準賣出稅另設0.1％。實際券商折扣、最低手續費、稅務及滑價需按自身情況更改。
- 0050使用相同日期與進場條件；股票池等權報酬另列為描述性基準。
- 不利幅度、每檔收盤路徑最大回撤及淨報酬分開。報表「平均個股最大回撤」不是實際連續資金組合的最大回撤。
- 十個日期可能重疊，尤其60日，**不是十次獨立統計實驗**。會顯示重疊次數。
- 本版新研究主要是持有期終點評價，**尚未回測首頁 ATR 防守參考價的完整停損／停利執行路徑**。價區與部位為規劃輔助，不可誤認淨報酬已模擬該停損制度。
- 沒有完整分鐘歷史及官方逐日漲停價序列，不報「盤中翻紅預測勝率」或「實際可成交漲停命中率」。

## 公布時點與補充資料
選配檔 `data/v19/optional_evidence.csv` 可使用下列欄位：
```text
ticker,available_at,source,revenue_yoy,eps_growth,eps_ttm,gross_margin,foreign_net,trust_net,dealer_net,margin_balance,holder_change
```
`available_at` 必須是真正可被使用的時間，使用台北時區或帶時區的 ISO 時間；未知就不要填造假的日期。淨買超及成交量都使用**股數**，不能把張數直接和股數相除。`revenue_yoy`、`eps_growth`、`gross_margin` 是百分數數值（例如12.5代表12.5％）；`holder_change` 是百分點。

由供應商日資料衍生的可用時間採保守延後，但仍不是原始公告時間認證；財報修訂資料可能存在修訂偏誤。這些限制不應冒稱全部已消除。單日法人值不得重複填成連買3日；自營商避險不能當自行買賣。

## 如何看畫面
- **研究分**：相對排序，不是漲停機率。
- **歷史平均／中位數／正報酬比例／樣本數**：截至該日已成熟、間隔開的相似價量案例；不是已校準的未來期望值。樣本不足明示，不填假零。
- **防守距離**：目前 ATR 與低點產生的參考距離；與歷史尾部損失分開。
- **來源與日期**：今日來源未驗證不能直接稱「舊日線」，保留實際日期與供應商。
- **盤中價**：個股診斷勾選後約20秒檢查；新核心不自動發布下單指令。分鐘價及較早成交價均標來源與原始時間。
- **業績＋回檔／低檔修復／突破加速**：以現有證據分類，不是「一定上漲」判斷。
- **欄位健康**：顯示有值、缺值及覆蓋率。測試資料不當成真實市場驗證。

## 命令列
```bash
pip install -r requirements.txt
streamlit run app.py

# 近3年、100檔、10日期；自動取資料並產出報表
python run_v19.py --years 3 --stocks 100 --dates 10 --horizons 5,20,60

# 沿用快取，不重新下載
python run_v19.py --cache-only --years 3 --stocks 100 --dates 10

# 指定母體時請至少10檔，以滿足預設共同樣本檢查
python run_v19.py --years 3 --stocks 100 --optional-data
```
個人電腦或網路可用的執行環境均可，不限定 Streamlit Cloud。程式支援 `--as-of`、`--seed`、`--trials`、`--data`、`--output`、`--tickers`。不建議在剛更改參數後反覆挑最好的十日期結果當證據。

## 產出檔案
- `v19_results.json`：日期、策略結果、成本、權重、調參軌跡、限制與資料識別碼。
- `comparison.csv`：10日期 × 3持有期 × 各比較策略。
- `selected_trades.csv`：原始選股、進出場日期、價格、淨報酬、未成交／缺資料原因。
- `weights_candidate.json`：截至最新資料可用的研究權重，不是自動交易授權。
- `factor_panel.csv.gz`：可以重查的逐股逐日因子。
- `v19_validation.md`：實際運算後才生成的摘要。

來源失敗時會留下 `download_manifest.json`；不覆蓋先前成功報表。Cloud容器永久重建仍可能失去本地檔案，不能把快取等同永久雲端儲存，請另行備份或設定持久化路徑。
